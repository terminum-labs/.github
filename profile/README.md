# Terminum Labs

**Confidence in what you ship.**

Your agents write the code. Who checks the product?

Terminum is continuous software verification for teams building with coding agents. It checks your running product against a shared spec of what it should do, adding a new checkpoint between CI and CD:

- **CI** checks the code
- **CV** (continuous verification) verifies the product
- **CD** deploys the change

Keep your agents and your workflow: Terminum works alongside Claude Code, Cursor and Codex.
